ADMINISTRADOR DE TAREAS 1.0.0
============================

Requisitos: Linux con GTK 4.14 o superior, libadwaita 1.5 o superior,
Python 3.10 o superior y psutil.

1. Instala las dependencias (Ubuntu / Debian):

   sudo apt update
   sudo apt install python3 python3-gi python3-psutil gir1.2-gtk-4.0 gir1.2-adw-1

   Fedora:
   sudo dnf install python3 python3-gobject python3-psutil gtk4 libadwaita

   Arch Linux:
   sudo pacman -S python python-gobject python-psutil gtk4 libadwaita polkit

2. Extrae el paquete y entra en la carpeta:

   tar -xzf Administrador-de-tareas-1.0.0.tar.gz
   cd Administrador-de-tareas-1.0.0

3. Instala la aplicación para tu usuario (no necesita sudo):

   ./install.sh

4. Ábrela desde el menú de aplicaciones como "Administrador de tareas",
   desde el acceso directo del escritorio o con:

   ~/.local/bin/administrador-tareas

También puedes probarla sin instalar con:

   ./run.sh
